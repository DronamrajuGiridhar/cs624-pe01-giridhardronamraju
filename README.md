# cs624-pe01-giridhardronamraju

# Input

The application receives input from information written by the developer in the source code: the user's name, degree program, and school. These values appear in three React Native Text components. No user typing is needed because the messages are predefined.

# Process

When Expo starts the application, React Native renders a View containing the three Text components. The StyleSheet controls the screen's appearance. The View uses flex: 1 to fill the available space, a yellow background, and alignment properties to center the messages horizontally and vertically. The Text styles set the font size, color, and alignment.

# Output

The application displays the user's name, degree program, and school as three separate lines of black text centered on a yellow screen. Expo lets the developer preview the result in a browser or on a mobile device using Expo Go. This demonstrates the input-process-output model in a mobile application built with React Native.
